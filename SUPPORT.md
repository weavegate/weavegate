# Support

Use this page to choose the right route for a question, defect, or security
report.

## Usage questions and design discussions

Use [GitHub Discussions](https://github.com/weavegate/weavegate/discussions)
when you need help using weavegate or want to discuss a design. Include what
you were trying to do and the commands you ran.

## Reproducible defects

Open a [GitHub Issue](https://github.com/weavegate/weavegate/issues) when you
can reproduce a defect. Include the reproduction command, relevant
`report.json` or `trace.json` artifacts, and the process exit code.

## Vulnerabilities

Follow the private reporting procedure in [`SECURITY.md`](SECURITY.md) when
reporting a vulnerability, and provide the information that procedure asks
for. Do not disclose vulnerabilities in an issue or GitHub Discussions.
